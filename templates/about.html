About Project

Personal Firewall using Python & Flask

Project Overview

This Personal Firewall project monitors network packets and applies custom allow/block rules based on user-defined IP addresses.

The application uses WinDivert for packet interception and Flask for the web-based management dashboard.

Frontend

HTML, CSS, JavaScript

Backend

Flask Framework

Firewall Engine

PyDivert + WinDivert

Features

  • Allow Mode Firewall
  • Block Mode Firewall
  • Real-Time Packet Filtering
  • Dynamic Rule Management
  • Live Log Monitoring
  • Multi-Page Dashboard
  • Persistent Rule Storage

Developer Information

Cybersecurity Project built using Python, Flask, PyDivert, JSON Storage, HTML, CSS and JavaScript.
